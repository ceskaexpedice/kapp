# Návody

Tato sekce obsahuje konkrétní postupy pro načítání a kurátorské zpracování dat.

## Dostupné návody

- [Import z Krameria](import-z-krameria.md) popisuje inkrementální sklizeň z API Krameria v5 a v7.
- [Kurátorské stavy](kuratorske-stavy.md) vysvětlují automatické i ruční přechody, licence a rok uvolnění.
- [Tabulkové importy](import-tsv.md) popisují převod historických TSV/Excel dat a párování posledního autora.

Pro nastavení vstupních zdrojů pokračujte do [konfigurace](../configuration/index.md). Plánované a cílené přepočty jsou popsané v části [Plánovač a updater](../operations/planovac-a-updater.md).
